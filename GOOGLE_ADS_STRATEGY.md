## 📦 Estrutura da Campanha — 3 Grupos de Anúncios

**Correspondência: Frase `"..."` (não ampla)**

### Grupo 1 — 🎯 Intenção Alta (Pessoas que já querem comprar)

CPC estimado: **R$ 4-6** | Taxa de conversão: **6-10%**

```
"sistema de estoque para mercadinho"
"sistema de estoque para mercearia"
"programa de controle de estoque"
"sistema pdv para mercado"
"software de estoque para pequeno comercio"
"app controle de estoque"
```

> Essas pessoas **já sabem** que precisam de um sistema. CPC mais alto, mas converte mais.

### Grupo 2 — 🔍 Intenção Média (Pessoas pesquisando soluções)

CPC estimado: **R$ 2-3,50** | Taxa de conversão: **4-6%**

```
"como controlar estoque de mercadinho"
"como organizar estoque de mercearia"
"controle de estoque pelo celular"
"pdv no celular para mercado"
"leitor codigo de barras estoque"
```

> Essas pessoas **têm o problema** mas ainda não decidiram a solução. CPC mais barato.

### Grupo 3 — 🆚 Concorrência (Pessoas comparando opções)

CPC estimado: **R$ 3-5** | Taxa de conversão: **5-8%**

```
"melhor sistema de estoque"
"sistema de estoque barato"
"sistema estoque gratis teste"
"alternativa bling estoque"
"alternativa tiny erp"
"sistema estoque simples"
```

> Essas pessoas **estão comparando** opções. Seu diferencial (15 dias grátis, sem cartão) mata aqui.
